## Built

### The Original Warehouse — New Orleans, 2018 · DECK_CONFIRMED
The deck (p.14) establishes the 2018 origin: a trash-built ring in a mouldy New
Orleans warehouse, drunk stunts, permits forged for a fashion show. **The
specific building is not established in the supplied research**, so the arena is
a stylised composite and the game does not name an address or imply a floor plan.
Source: CHOKE HOLE 10.3 Pitch Deck p.14; https://www.chokehole.com/
